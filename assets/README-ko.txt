도서관 책 받기 미니게임 — 모션 스프라이트

cat-reshelve-5frames.png: 고양이 책 꽂기 5프레임, 왼쪽부터 준비 → 팔 뻗기 → 밀기 → 손 떼기 → 회복.
권장 시작 설정: 프레임당 200ms, 전체 1초.

librarian-drop-5frames.png: 사서 책 떨어뜨리기 5프레임, 왼쪽부터 준비 → 접촉 → 밀기 → 책 기울어 떨어짐 → 회복.
권장 시작 설정: 프레임당 120ms, 전체 0.6초.

두 PNG는 투명 배경이며 캐릭터와 움직이는 책만 포함합니다.
게임에서는 각 JSON의 rect를 원본 PNG에서 읽을 프레임 영역으로 사용하세요. 그림별 여백이 달라 단순 5등분하면 일부가 잘릴 수 있습니다.
offset_in_canvas 위치에 해당 프레임을 그리면 모든 프레임을 640×768의 공통 영역 안에 배치할 수 있습니다.
anchor_in_canvas는 고양이 발 / 사서가 서가를 짚는 기준 위치입니다. 프레임을 바꿀 때 이 기준점을 고정하면 위치가 안정됩니다.
PNG의 픽셀을 임의로 다시 그리거나 리사이즈하지 않고, 프레임 영역과 기준점 정보만 함께 제공합니다.
